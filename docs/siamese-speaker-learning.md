# Siamese方式の話者識別

## 実装の範囲

既存のECAPA-TDNN CoreMLモデルを固定の特徴抽出器として利用し、192次元埋め込みの後段に共有する学習可能な対角射影層を追加した。音声からECAPA全層を再学習する実装ではない。

2つの枝は同じ `f(x) = normalize(diag(scales) * x)` を使う。コサイン類似度sに対し、同一話者は `(s-1)^2`、異話者は `max(0,s-0.2)^2` を最小化する。対数スケールに対する解析勾配で160エポック学習し、正則化とスケール上限・下限を設けた。従来のコサイン照合を単にSiameseと呼び替えたものではない。

距離学習の参考：[Semi-Supervised Contrastive Learning with Generalized Contrastive Loss and Its Application to Speaker Recognition](https://arxiv.org/abs/2006.04326)。この論文のモデルや報告精度を再現したものではなく、本実装は登録データで学ぶ小さなローカル射影層である。

## 使い方

1. この変更をアプリへ反映した後、「音声と声紋 → 声紋を登録」で名前を指定して登録する。
2. 2人以上について、それぞれ4回以上、別々に録音する。毎回異なる読み上げ文を案内する。
3. 「音声と声紋 → Siamese学習の状態…」で回数、学習状態、検証結果を確認する。
4. 学習・検証に通れば「Siamese学習済み照合を使う」がオンの状態で自動適用される。オフにすると従来の照合に戻る。

既存声紋の平均ベクトルから独立した録音を復元することはできないため、既存プロファイルを学習サンプルの水増しに使わない。既存の声紋は保存したまま従来照合に使用する。

## 教師データと検証

- 名前を指定した手動登録で、音質チェックに通った録音のみ採用する。
- 1回の録音は1セッション。重なる窓を分割して学習用・検証用に分けない。同一セッションIDの再投入、完全に同一の特徴量の再登録は回数を増やさない。
- 推定した話者名、通常会話中の適応更新、チャットの表示名はSiameseの教師ラベルにしない。
- 上限16人、各12録音。バックグラウンド学習は同時に1件、追加登録時は最新状態にまとめる。
- 各話者の2セッションを検証用に隔離。残りから同一・異話者ペアを同数、最大128ペアずつ選んで学習する。
- 閾値と順位差は学習用録音のみから決める。検証用録音は重み・閾値の最適化に使わない。
- 検証ペアで誤受入が0、誤拒否率が固定射影より悪化せず、contrastive lossが改善することを採用条件とする。
- さらに検証録音を学習用の登録録音へ照合する検証を行い、別人への誤識別なし、正解数の悪化なし、全話者で少なくとも1録音が正しく識別されることを要求する。
- 条件を満たさなければ従来方式を維持する。追加録音で再評価できる。

検証に繰り返し使用した登録データに対する結果は独立した実運用テスト精度ではない。少数の登録者での誤受入0%を、未知話者・雑音・同時発話・別マイクでも誤識別しない保証として扱わない。

## 推論と不明判定

入力と各話者の複数の明示的登録ベクトルへ同じ射影を適用し、録音ごとの類似度の中央値で順位付けする。1位が閾値以上、2位との差が必要マージン以上の場合だけ名前を返す。類似度は確率ではない。

Siameseが有効な照合で却下された音声は「不明」のままにする。従来のピッチ補正・スコア補正・時間多数決で名前を復活させない。登録者集合が学習データの集合と一致しない場合は従来方式を使う。Siamese使用時は推定結果による声紋更新を行わない。

## 保存と既存機能への修正

- `~/Library/Application Support/GravityReader/siamese_voice_v1.json` に特徴量、録音ID、話者ラベル、モデル、検証結果を原子的に保存する。
- Siamese学習はローカルで完結し、新しいAPIキー・クラウド送信・録音ファイルの保存は不要。既存の文字起こし・会話APIとは別の処理である。
- 既存の `voice_profiles.json` は形式を維持し、MFCCとneuralの切替時に他モードの登録を消さない。
- 声紋の明示的削除は対応するSiamese資料とモデルも無効化する。進行中の学習結果が削除後に復活しないよう世代を照合する。
- 破損・非対応の学習ファイルは自動上書きしない。不正値、次元違い、未検証モデルは使用しない。
- マイク入力の実サンプルレートを保持し、声紋処理前に44.1kHzへ変換する。通常リスニング中の手動登録でも12秒分のバッファを確保する。
- 学習状況は登録・学習完了時だけ通知し、照合ごとの情報は会話ログへ大量表示しない。

## 検証方法と限界

単体テストは、共有射影の対称性、有限差分と解析勾配の一致、合成特徴量での学習、録音単位の分離、検証失敗時の拒否、保存復元、進行中の学習の無効化、従来声紋の保護、照合経路の統合を確認する。実ユーザーの声を収集して学習した結果ではない。

新しい実録音での識別率・誤受入率・誤拒否率はまだ未測定。ECAPA本体・特徴量前処理の品質、重なった発話や未知話者に対する識別の限界は残る。アプリのパッケージ更新・再起動はユーザー承認後に別途実施する。
